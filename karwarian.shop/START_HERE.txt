🚀 FASTEST WAY TO START (2 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WINDOWS USERS:
  1. Double-click: setup.bat
  2. Wait for installation
  3. Create admin username and password when prompted
  4. Website will open automatically at http://localhost:8000

UBUNTU/LINUX USERS:
  1. Open terminal in this folder
  2. Run: chmod +x setup.sh
  3. Run: ./setup.sh
  4. Create admin username and password when prompted
  5. Visit: http://localhost:8000

That's it! Your website is running!

✅ WHAT TO DO AFTER SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. VISIT THE WEBSITE
   Open http://localhost:8000 in your browser
   You'll see the home page (currently empty)

2. LOGIN TO ADMIN PANEL
   Go to http://localhost:8000/admin
   Login with your admin credentials
   This is where you manage all content

3. ADD SITE STATISTICS
   In admin panel:
   - Click "Site Statistics" under CORE
   - Click "Add Site Statistics"
   - Set: Beaches=12, Matrimony=500, Events=50, Vendors=200
   - Click "Save"
   - Refresh home page to see statistics

4. ADD PLACE CATEGORIES
   In admin panel:
   - Click "Place Categories" under PLACES
   - Add categories like:
     * Name: Beaches, Slug: beaches, Icon: 🏖️
     * Name: Forts, Slug: forts, Icon: 🏰
     * Name: Islands, Slug: islands, Icon: 🏝️
   - Click "Save" for each

5. ADD SOME PLACES
   In admin panel:
   - Click "Places" under PLACES
   - Click "Add Place"
   - Fill in name, description, category
   - Upload an image (optional)
   - Click "Save"
   - Add 3-5 places

6. REPEAT FOR OTHER SECTIONS
   - Add News Categories and News Articles
   - Add Job Categories and Jobs
   - Add Service Categories and Services
   - Add Bus Timings

7. VIEW YOUR WEBSITE
   Refresh http://localhost:8000
   All your content will appear!

❓ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLEM: Python not found
SOLUTION: Install Python 3.8+ from python.org

PROBLEM: Port 8000 already in use
SOLUTION: 
  Windows: netstat -ano | findstr :8000, then taskkill /PID <number> /F
  Linux: lsof -ti:8000 | xargs kill -9

PROBLEM: Module not found
SOLUTION: Make sure virtual environment is activated
  Windows: venv\Scripts\activate
  Linux: source venv/bin/activate

PROBLEM: Can't access admin panel
SOLUTION: Make sure you created a superuser during setup
  Run: python manage.py createsuperuser
